# Rock Paper Scissors Game

A browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript.

## Overview

This project allows users to play Rock Paper Scissors against a computer-controlled opponent. The game generates random computer moves, displays round results, tracks wins, losses, and ties, and saves score data using the browser's localStorage.

## Features

- Play Rock, Paper, or Scissors against the computer
- Random computer move selection
- Displays the result and moves chosen after each round
- Tracks wins, losses, and ties
- Saves score progress using localStorage
- Reset score functionality
- Keyboard controls for Rock, Paper, and Scissors
- Auto Play mode with customizable play speed
- Dynamic speed input handling

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Start playing.

## Purpose

This project was created to practice JavaScript fundamentals, including:

- Functions
- DOM manipulation
- Event handling
- User input handling
- setInterval for repeated actions
- Program state management
- Data storage using localStorage
